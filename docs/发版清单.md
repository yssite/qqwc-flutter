# 发版清单

每次出包按顺序走一遍，避免文档版本号落后（v1.3.5 之前的 README 就因为漏更新，一直停在旧版本）。

1. `pubspec.yaml`：`version: X.Y.Z+XYZ00`（versionCode 用 `X*10000 + Y*100 + Z`）
2. `README.md` 顶部「最新版本」改成 `vX.Y.Z`
3. `CHANGELOG.md` 顶部新增 `## vX.Y.Z` 段落（用户能看到的更新说明）
4. 构建并核对签名：
   ```powershell
   flutter test
   flutter build apk --release
   flutter build apk --release --split-per-abi
   & "D:\Android_SDKs\build-tools\36.0.0\apksigner.bat" verify --print-certs build\app\outputs\flutter-apk\app-release.apk
   ```
   签名应为 `CN=Android Debug`（当前策略见 README「签名」一节）。
5. 归档到 `dist/`，提交并打 tag，然后发 Release：
   ```powershell
   git add -A; git commit -m "feat(vX.Y.Z): ..."
   git tag -a vX.Y.Z -m "Flutter 网测 vX.Y.Z"
   git push origin main; git push origin vX.Y.Z
   gh release create vX.Y.Z --title "..." --notes-file build\release_notes_XYZ.md dist\*.apk
   ```

> 应用内更新的版本判断读取 `Release` 的 `tag_name`，所以 tag 必须是 `vX.Y.Z` 形式。
